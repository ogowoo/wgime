# WgIme 使用说明

WgIme 是一个**免安装的单文件悬浮输入法**：支持拼音、五笔、混合、英汉词典四种模式，带词频学习、简拼、模糊音、造词，并可导入常见码表扩充词库。

## 1. 快速开始

1. 双击运行 `wgime.bat`（无窗口启动，任务栏托盘出现圆角方块"中"字图标）。
2. 默认输入法为**开**（托盘图标：**彩色大字=开，灰色大字=关**）。
3. 在任意文本框输入拼音或五笔编码，候选条即出现在屏幕左下方；候选条可按住鼠标左键拖动，位置自动记忆。
4. 退出：右键托盘图标 → **退出**。
5. 开机自启（可选）：把 wgime.bat 的快捷方式放进 `shell:startup` 文件夹即可。

> 排错提示：若启动无反应，先在 cmd 里执行 `set WGIME_DEBUG=1` 再运行 wgime.bat，控制台会保留错误信息；日志见 `%TEMP%\WgIme_error.log`。

## 2. 快捷键总表

| 按键 | 功能 |
|---|---|
| **Shift 轻点**（单独按下松开） | 开 / 关输入法 |
| **Ctrl + `**（反引号） | 切换模式：混合 → 拼音 → 五笔 → 词典 → 混合… |
| **Ctrl + Alt + C** | 造词（先把 2-8 个汉字复制到剪贴板） |
| 字母 a-z | 输入编码 |
| 空格 | 选第 1 个候选 |
| 数字 1-9 | 选第 N 个候选 |
| `=` 或 PgDn | 候选下一页 |
| `-` 或 PgUp | 候选上一页 |
| Backspace | 删除最后一个编码 |
| Esc | 清空编码 |
| Enter | 把输入的编码原样上屏（英文上屏） |
| Shift + 字母 | 大写英文直接上屏（不拦截） |
| **`[` / `]`（有编码时）** | 以词定字：取候选 1 的首字 / 尾字上屏（如 `zhongguo` 选词后按 `]` 上屏"国"） |
| **`rq` / `sj` / `xq`** | 快捷候选：日期（多种格式）/ 当前时间 / 星期 |
| **`vf`** | 符号/表情面板：数字选分类，再选符号上屏（见 §4） |
| **`v` + 数字**（如 `v1234`） | v 模式：人民币大写金额 + 千分位（v 后直接按数字输入） |
| **Ctrl + Shift + F** | 简体 / 繁体输出切换（候选与上屏都转繁体） |
| **五笔模式 `z` 通配符** | 记不清的码用 `z` 顶位，如 `yzzz` 列出全部 4 码候选 |

## 3. 四种模式

| 模式 | 托盘图标 | 说明 |
|---|---|---|
| 混合（默认） | 中 | 五笔候选优先，其后补拼音候选 |
| 拼音 | 拼 | 全拼 + 简拼（`zg→中国`）+ 模糊音 |
| 五笔 | 五 | 纯五笔；四码全码自动上屏首选（无需空格；同码多词想选择时退格回三码看列表） |
| 词典 | 译 | 输入英文单词→中文释义；输入汉字拼音/简拼→英文翻译（候选可选定上屏） |

模糊音自动支持：zh/z、ch/c、sh/s、ang/an、eng/en、ing/in、n/l。

## 4. 中文标点

输入法开启时，常见标点自动映射为中文：

| 按键 | 输出 |
|---|---|
| `,` | ， |
| `.` | 。 |
| `;` | ； |
| `:` | ： |
| `?` | ？ |
| `\` | 、 |
| `[` / `]` | 【 】 |
| `$`（Shift） | ¥ |
| `'` / `"` | ‘ ’ / “ ”（自动交替配对） |

需要英文标点时，Shift 轻点关闭输入法即可。

**符号与表情（vf 面板）**：输入 `vf`，数字键选分类（`1` 单位 `2` 标点 `3` 图形 `4` 数学 `5` 表情），分类内按数字或空格选符号直接上屏；`=`/`-` 翻页，退格返回分类列表，Esc 或 Enter 关闭面板。共 141 个符号（℃ ℓ № … 《 》 ★ ☆ ± ≤ ∞ α β 😀 ❤️ 等）；emoji 在候选条以**彩色图片**显示（内嵌微软 Fluent Emoji 3D 图形，MIT 协议，Windows 11 同款风格）、上屏正常；符号不参与词频学习。注：`vf` 为面板专用，与词典同码时面板优先。

## 5. 造词

- **手动**：复制 2-8 个汉字 → 按 `Ctrl+Alt+C`，弹出气泡提示成功后，用该词的全拼即可打出（也进入简拼，如"中国"可用 `zg`）。
- **自动**：90 秒内连续选择 2-4 个单字（如先选"中"再选"国"），WgIme 自动把这几个字组成词并记住。
- 用户词存于 `%LOCALAPPDATA%\wgime\userwords.txt`，可手动编辑（格式：`码 词1 词2…`）。
- **管理用户词**：托盘右键 → **用户词表…**，列表显示全部用户词（词 + 编码，按词排序），勾选后点 **删除选中** 即可删除（全选/全不选按钮可用）；删除立即生效并写回文件。

## 6. 扩展词库（txt）

把以下文件放在 wgime.bat 同目录即可自动加载（下次启动生效）：

| 文件 | 词典 | 格式 |
|---|---|---|
| `py.txt` | 拼音 | 每行 `拼音码 词1 词2…`（空格分隔） |
| `wb.txt` | 五笔 | 每行 `五笔码 词1 词2…` |
| `ec.txt` | 英汉 | 每行 `英文单词 中文释义1 释义2…` |

- 文件必须为 UTF-8 编码；同码行会**覆盖**内置词典该码的候选（想要"追加不覆盖"请用"导入码表"功能，它写入的 import 文件是叠加保留的）。
- 修改这些文件后**重启 WgIme** 生效（或触发一次码表导入，导入会热重载全部词典）。

## 7. 码表导入（常见码表转换导入）

托盘右键菜单 → **导入码表…**，选择一个码表文件即可转换并导入。

### 7.1 支持的格式

| 格式 | 示例 | 说明 |
|---|---|---|
| Rime 码表 `*.dict.yaml` | `朗逸<TAB>yvqk`、`科一<TAB>tugg<TAB>100` | 词在前，TAB 分隔，尾部数字为权重（自动丢弃）；`#` 注释、`## 分组`、`---`/`...`/`key: value` 头自动跳过 |
| 编码在前的 txt | `yvqk 朗逸`、`abc 工 一` | 空格或 TAB 分隔均可（小小输入法、wgime 自身格式等） |
| 词在前的 txt | `中国 khlg` | 空格分隔，首列为汉字 |
| 英汉词表 | `apple<TAB>苹果` | 英文单词 + 中文释义 |

- 编码文件支持 UTF-8 与 GBK/GB18030 中文编码，自动识别；文件需小于 64MB。
- 不支持搜狗细胞词库 `.scel` 等二进制格式。

### 7.2 操作步骤

1. 托盘 → **导入码表…**，选择码表文件；
2. 弹窗确认：**目标词库**（五笔/拼音/英汉，默认按文件名猜测：含 wubi/wb/五笔→五笔，pinyin/py/拼音→拼音，english/ec/英汉→英汉）+ **源格式**（默认自动检测，TAB 行判为词在前，纯 ASCII 首列判为编码在前）；
3. 点 **导入**，气泡显示"新增 X 码 / Y 词 → import_wb.txt"；词典**立即生效，无需重启**。

### 7.3 导入结果与撤销

- 转换结果写入 wgime.bat 同目录的 `import_wb.txt` / `import_py.txt` / `import_ec.txt`（按目标词库），启动时与 py/wb/ec.txt 同样逻辑自动加载。
- **重复导入同一文件不会产生重复条目**（自动去重，已有候选保持在前）。
- **撤销导入**：删除对应 `import_*.txt` 并重启 WgIme（或再导入一次任意码表触发重载）。
- 上限：每码最多 300 词、全表 50 万码，超出部分截断并在气泡中提示；含空格词条（如 `AirPods Pro`）会被跳过。

### 7.4 导入后打不出来怎么办

1. 确认模式正确（导入五笔码表后请 `Ctrl+\`` 切到五笔或混合模式）；
2. 检查 `import_wb.txt` 是否生成、内容是否为 `码 词…` 格式；
3. 尝试重启 WgIme；仍不行看 `%TEMP%\WgIme_error.log` 与 `%LOCALAPPDATA%\wgime\mb_error.log`。

## 8. 固化码表（烘焙进内置）

把**当前合并后的全部词库**（内置 + 扩展 txt + 导入文件 + 用户词）写回 `wgime.bat` 的内置码表——之后目录下的 txt 码表文件就可以放心删除，bat 变成自包含单文件。

**操作步骤**

1. 托盘右键 → **固化码表…**；
2. 勾选要固化的词库（五笔/拼音/英汉，各自显示体积），可选勾选"完成后删除目录中对应的 txt / import 码表文件"（默认不勾）；
3. 点 **固化**，稍候气泡提示结果。

**说明与注意事项**

- 固化前自动备份为带时间戳的 `wgime.bat.bak-日期时间` 文件，**滚动保留最新 7 份**（备份写失败则整个固化中止，bat 不会被改动），出问题从备份还原即可。
- 固化**立即生效**（词典本来就在内存里），下次启动时自动重建一次缓存（几秒钟）。
- bat 体积会增大到十几 MB：启动时解析会略慢，但词典加载仍走缓存秒开。
- 词频、上次选择、用户词、候选条位置等学习数据**不参与固化**，仍然独立保存。
- 固化写入的是"当下"的快照：之后新导入的码表仍通过 `import_*.txt` 叠加，再固化一次即可并入。
- 还原：把选定的 `wgime.bat.bak-*` 备份复制回 `wgime.bat`，或把 txt 文件放回目录（重复条目自动去重）。

## 9. 配置与扩展（config.txt）

在 wgime.bat 同目录放一个 `config.txt`（UTF-8）即可配置以下内容。没有的话，点托盘 **重载配置** 会自动生成带注释的模板。

| 键 | 说明 | 默认 |
|---|---|---|
| `fuzzy = zh-z,ch-c,…` | 模糊音对，逗号分隔；留空或 `none` 关闭 | 内置 7 组 |
| `showcode = 1/0` | 候选上显示反查编码：拼音/混合模式显示五笔码，五笔模式显示拼音（也可用托盘"反查编码"临时开关） | 0 |
| `paste = key/on/auto/off` | 上屏方式：`key`=逐字符 Unicode 注入（**默认**，不走剪贴板，无竞态不掉字）；`on`=剪贴板粘贴（上屏后约 0.3 秒自动恢复你原来的剪贴板）；`auto`=管理员窗口用剪贴板、其余走 key；`off`=纯按键 | key |
| `shuangpin = xiaohe/ziranma/ms/none` | 双拼方案：小鹤 / 自然码 / 微软（微软的 `ing` 在 `;` 键） | none |
| `trad = 1/0` | 繁体输出（也可 `Ctrl+Shift+F` 或托盘"简繁输出"临时切换） | 0 |
| `starton = 1/0` | 启动时输入法默认开/关（`Shift` 轻点随时切换） | 1 |
| `phrase = 编码<TAB>文本` | 自定义短语：输入编码出长文本，文本可含空格，如 `phrase = dz	地址: 某某路5号` | 无 |

- 短语优先：编码命中短语时它排候选第一位，空格直接上屏；
- 配置改动后点托盘"重载配置"即时生效（模糊音、短语、显示编码、粘贴模式、双拼）；
- `;` 或 `#` 开头为注释行。

**双拼**（`shuangpin = xiaohe/ziranma/ms`）：两键出一个音节，如小鹤 `vsgo` → 中国、`pb` → 拼、`tm` → 天；简拼、模糊音、用户词、以词定字都基于还原后的全拼照常工作；五笔与词典模式不受影响。注意：双拼开启时 **vf 符号面板**与 **rq/sj/xq 快捷键**停用（避免与真实音节冲突，如小鹤 `vf`=真、`xq`=修）；微软方案里 `;` 键用于输入 `ing`。

**繁体输出**：`Ctrl+Shift+F` 或托盘"简繁输出"切换，打开后候选条与上屏均为繁体（OpenCC 单字映射，3602 字；如"软件"→"軟件"）。个别上下文相关字取最常用繁体（发→發、干→乾、后→後），不做词组级消歧。

**v 模式**：输入 `v` 后直接按数字（如 `v1234`），候选 1 为人民币大写"壹仟贰佰叁拾肆元整"（支持到 16 位：万/亿/兆），候选 2 为千分位"1,234"；空格/数字直接上屏。双拼与五笔模式下停用（避免与编码冲突）。

**个别程序想单独切换上屏方式（不改全局）**：在该程序的窗口里右键托盘 → **这个程序改用剪贴板上屏**（再点一次还原）。选择只影响这一个程序，记录在 `%LOCALAPPDATA%\wgime\pastemode.txt`（`程序名.exe=clipboard/sendkeys/key`），可手动编辑。

## 10. 数据与文件一览

**wgime.bat 同目录**

| 文件 | 作用 |
|---|---|
| `wgime.bat` | 程序本体 |
| `config.txt` | 配置（模糊音/短语/显示编码/粘贴模式），托盘"重载配置"可生成模板 |
| `wgime.bat.bak-时间戳` | 固化码表前的滚动备份（自动保留最新 7 份） |
| `py.txt` `wb.txt` `ec.txt` | 扩展词典 |
| `import_py.txt` `import_wb.txt` `import_ec.txt` | 码表导入产物 |

**`%LOCALAPPDATA%\wgime\`（用户数据，删除即恢复初始状态）**

| 文件 | 作用 |
|---|---|
| `wgime.mb` | 词典缓存（可删除，自动重建） |
| `userdict.txt` | 词频学习记录 |
| `lastpick.txt` | 每个编码上次选中的词 |
| `userwords.txt` | 用户造词 |
| `pos.txt` | 候选条位置 |
| `pastemode.txt` | 按进程上屏方式覆盖（托盘"这个程序改用剪贴板上屏"自动维护） |
| `WgIme.*.dll` | 程序预编译组件（自动维护） |

## 11. 常见问题

**Q：某些窗口里打不出字？**
个别程序对默认注入方式不友好：在该窗口右键托盘 → **这个程序改用剪贴板上屏**（只影响这一个程序）；或改 config.txt 的 `paste = on` / `paste = auto` 对比。

**Q：提示"WgIme is already running"？**
WgIme 是单实例程序，请从托盘退出旧实例再启动。

**Q：不小心把输入法关了怎么办？**
Shift 轻点一下即重新打开；托盘图标灰色=关、彩色=开。

**Q：导入的码表不想要了？**
删除 bat 目录对应的 `import_*.txt`，再通过托盘"导入码表…"任意导入一个文件触发重载，或重启 WgIme。

**Q：如何重置全部学习数据？**
退出 WgIme，删除 `%LOCALAPPDATA%\wgime\` 下的 `userdict.txt`、`lastpick.txt`、`userwords.txt` 后重启。

**Q：固化后还能删目录里的 txt 码表文件吗？**
可以——固化已把合并词库写进了 bat 内置表，删除 `py.txt`/`wb.txt`/`ec.txt` 和 `import_*.txt` 不再丢词（下次启动自动重建缓存）。改主意了就从任一份 `wgime.bat.bak-时间戳` 备份还原（自动保留最新 7 份）。

**Q：某些窗口（Notepad 等）上屏出乱码？**
原因是旧式 SendKeys 注入与目标窗口里的系统输入法冲突。默认上屏方式已是逐字符 Unicode 注入（`paste = key`），不经过剪贴板也不经过旧式按键模拟；若个别程序表现异常，可在 config.txt 换 `paste = on`（剪贴板粘贴）或 `paste = off`（纯按键）对比。

**Q：在管理员窗口（任务管理器等）里打不出字？**
WgIme 以普通权限运行时，系统安全机制（UIPI）会拦截它向管理员窗口的任何注入（粘贴也一样）。以管理员身份运行 WgIme 即可在管理员窗口输入；或者复制内容后在目标窗口手动 Ctrl+V。
